# 학습 매뉴얼 정리

제공된 최신 매뉴얼은 LangGraph 기반 Adaptive RAG와 근거 판정을 다루며, 노드별 동작 확인과 전체 실행 사례를 설명합니다.

## 확인 순서

1. 문서 경로와 문서 ID 라우팅을 확인합니다.
2. 청크의 출처·페이지 메타데이터와 검색 반환을 확인합니다.
3. 질문 변형과 답변의 출력 형식을 확인합니다.
4. 공유 상태에 각 노드의 결과가 남는지 확인합니다.
5. 재검색·재답변·종료 분기가 의도대로 연결되는지 확인합니다.
6. 전체 실행 로그를 읽으며 검색 범위와 최종 답변을 비교합니다.

## 기본 흐름과의 비교

| 구성 | 검색 전략 | 판정 후 처리 |
|---|---|---|
| 기본 RAG | 고정된 검색 개수와 원문 질문 | 생성 답변으로 종료 |
| 고정 검색 + Judge | 고정된 검색 범위 | 근거 여부를 확인하고 종료 |
| Adaptive RAG + Judge | 재시도 시 검색 개수·질문 표현 확장 | 재검색 또는 재답변 후 다시 판정 |

매뉴얼의 비교 사례는 검색 범위 확장과 판정 루프의 역할을 설명합니다. 집계된 평가 데이터나 반복 측정 결과가 제공된 것은 아니므로 성공률·정확도 향상 수치로 환산하지 않았습니다.

## 정리한 엔지니어링 관점

**검색과 답변의 문제를 구분합니다.** 자료가 부족한 경우 검색을 다시 하고, 자료는 있으나 답변이 근거를 벗어나는 경우 답변을 다시 생성합니다.

**검색량과 정보량을 구분합니다.** 여러 질문으로 검색한 결과가 중복되면 후보 수가 늘어도 실제 근거가 늘지 않을 수 있습니다. 중복 제거 전후의 결과를 함께 봅니다.

**추적 정보를 남깁니다.** 문서 ID·출처·페이지와 노드별 상태를 연결해 어떤 자료가 최종 답변에 사용됐는지 확인합니다.
