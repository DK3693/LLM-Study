# LLM Study

**Study notes on local model loading, retrieval-augmented generation, and graph-based agent workflows.**

[한국어](README.md) · [Study map](docs/STUDY_MAP.md) · [Adaptive RAG](docs/ADAPTIVE_RAG.md) · [Sources](SOURCES.md)

The portfolio organizes supplied training examples and a study manual into a technical map of Transformers, Ollama, LangChain, LangGraph, vector retrieval, MCP, and parameter-efficient fine-tuning.

The featured workflow routes a question to documents, retrieves evidence, generates an answer, and selects between finalization, re-retrieval, and re-answering. The notes explain shared state, metadata, query expansion, and retry bounds.

A model-loading notebook is included with execution outputs and local metadata removed. Instructor notebooks, training datasets, model weights, vector databases, and credentials are not distributed here.

These materials document study topics and example architecture. They do not present training examples as independently authored production systems or claim a new benchmark result.
